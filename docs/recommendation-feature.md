# Рекомендательная система Nova Market

## Типы рекомендаций

- Персональные рекомендации.
- Групповые рекомендации.
- Рекомендации на основе похожих товаров.
- Рекомендации для новых пользователей.

## Проверка

1. Открыть прототип.
2. Выбрать профиль пользователя.
3. Посмотреть персональные рекомендации.
4. Переключить профиль.
5. Сравнить результаты.
6. Отключить персонализацию.
