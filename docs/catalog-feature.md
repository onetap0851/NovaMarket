# Каталог Nova Market

## Возможности каталога

- Просмотр товаров по категориям.
- Поиск товаров по названию.
- Фильтрация товаров.
- Просмотр карточек товаров.
- Добавление товаров в корзину.
- Просмотр стоимости товаров.

## Проверка

1. Открыть прототип.
2. Перейти в каталог.
3. Найти товар через поиск.
4. Открыть карточку товара.
5. Добавить товар в корзину.
